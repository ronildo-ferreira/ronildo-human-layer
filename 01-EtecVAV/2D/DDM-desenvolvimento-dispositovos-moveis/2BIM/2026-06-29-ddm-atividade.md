# 📚 Atividade de Pesquisa — App Inventor

## Tema
**App Inventor: Manipulação de Banco de Dados no Dispositivo (TinyDB)**

---

## 🎯 Objetivo

Pesquisar o funcionamento do componente **TinyDB** do MIT App Inventor, compreendendo como os aplicativos podem armazenar e recuperar informações diretamente no dispositivo móvel, sem a necessidade de acesso à Internet.

O objetivo desta atividade é desenvolver a capacidade de pesquisa, interpretação de documentação técnica e produção de um material acadêmico utilizando normas de documentação.

---

## 👥 Modalidade

- Atividade em **grupo**.

---

## 📅 Entrega

- Produzir o trabalho em formato **Markdown (`.md`)**.
- Enviar o arquivo pelo **Microsoft Teams**.
- Como esta atividade faz parte do **portfólio da disciplina**, o mesmo arquivo também deverá ser publicado no **GitHub do grupo**, seguindo a organização do repositório.
- Seguir todas as orientações apresentadas no **PDF disponibilizado pelo professor**.

> **Importante:** Como esta atividade também será utilizada para registro de frequência, **todos os integrantes do grupo deverão enviar exatamente o mesmo arquivo no Microsoft Teams**.

# 📖 Roteiro da Pesquisa

A pesquisa deve responder, no mínimo, às seguintes questões.

## 1. O que é o MIT App Inventor?

Explique:

- O que é o App Inventor.
- Para que ele é utilizado.
- Quais são suas principais vantagens para iniciantes.

---

## 2. O que é o TinyDB?

Explique:

- O que é o componente TinyDB.
- Qual sua finalidade.
- Onde os dados são armazenados.
- Quais são suas vantagens e limitações.

---

## 3. Funcionamento do TinyDB

Explique como funciona o armazenamento de dados utilizando:

- Tags (chaves)
- Valores
- Gravação de informações
- Leitura de informações
- Atualização de dados
- Remoção de dados

Sempre que possível, utilize exemplos para ilustrar o funcionamento.

---

## 4. Componentes Relacionados

Pesquise a função dos principais blocos utilizados com o TinyDB, como por exemplo:

- StoreValue
- GetValue
- ClearTag
- ClearAll

Explique quando cada um deve ser utilizado.

---

## 5. Aplicações Práticas

Pesquise situações em que o TinyDB pode ser utilizado.

Exemplos:

- Lista de tarefas
- Agenda de contatos
- Cadastro de clientes
- Lista de compras
- Aplicativo de anotações
- Controle financeiro
- Jogos com armazenamento de pontuação

Explique por que o TinyDB é adequado para essas aplicações.

---

## 6. TinyDB × TinyWebDB

Pesquise as diferenças entre:

- TinyDB
- TinyWebDB

Explique:

- Onde os dados ficam armazenados;
- Quando utilizar cada um;
- Vantagens e desvantagens de cada solução.

---

## 7. Boas Práticas

Pesquise boas práticas para trabalhar com armazenamento de dados no App Inventor.

Exemplos:

- escolha de nomes para as Tags;
- organização dos dados;
- atualização das informações;
- exclusão de dados desnecessários;
- cuidados para evitar perda de informações.

---

## 8. Conclusão

Escreva um pequeno texto respondendo:

- Qual a importância do TinyDB no desenvolvimento de aplicativos?
- Em quais tipos de aplicativos ele pode ser utilizado?
- Quais conhecimentos o grupo adquiriu durante a pesquisa?
