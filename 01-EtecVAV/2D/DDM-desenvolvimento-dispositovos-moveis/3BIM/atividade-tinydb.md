# Atividade Prática — App Inventor

## Aplicativo de Lista de Tarefas com TinyDB

## Objetivo

Desenvolver um aplicativo simples no **MIT App Inventor** para cadastrar, visualizar e excluir tarefas.

As informações deverão ser armazenadas no próprio dispositivo utilizando o componente **TinyDB**, permitindo que as tarefas continuem disponíveis mesmo depois que o aplicativo for fechado.

Muitas pessoas precisam anotar atividades importantes durante o dia, como:

* trabalhos escolares;
* exercícios;
* compromissos;
* tarefas domésticas;
* atividades de projetos.

O grupo deverá desenvolver um aplicativo que permita registrar essas tarefas no celular.

As tarefas não podem desaparecer quando o aplicativo for fechado. Para isso, os dados deverão ser armazenados com o componente **TinyDB**.

---

# Funcionalidades obrigatórias

O aplicativo deverá permitir:

1. Digitar uma nova tarefa.
2. Adicionar a tarefa a uma lista.
3. Mostrar todas as tarefas cadastradas.
4. Salvar automaticamente a lista no TinyDB.
5. Recuperar as tarefas quando o aplicativo for aberto.
6. Selecionar uma tarefa da lista.
7. Excluir a tarefa selecionada.
8. Apagar todas as tarefas.

---

# Funcionalidades opcionais

Os grupos que concluírem as funcionalidades obrigatórias poderão acrescentar melhorias.

## Sugestões

* marcar uma tarefa como concluída;
* mostrar a quantidade de tarefas cadastradas;
* cadastrar uma data para a tarefa;
* cadastrar uma categoria;
* utilizar cores diferentes;
* adicionar prioridade: baixa, média ou alta;
* permitir editar uma tarefa;
* mostrar uma mensagem de confirmação;
* criar uma tela de informações sobre o aplicativo.

Essas funcionalidades são opcionais e não devem impedir a conclusão da versão básica.

# Entrega

O grupo deverá:

Publicar o projeto no GitHub.


# Orientações importantes

* Utilize nomes claros para os componentes.
* Não utilize espaços ou acentos nos nomes dos componentes.
* Teste o aplicativo durante o desenvolvimento.
* Não deixe todos os testes para o final.
* Salve cópias do arquivo `.aia`.
* Faça commits durante o desenvolvimento.
* Não copie um projeto pronto da Internet.
* Todos os integrantes devem compreender o funcionamento dos blocos.
* Priorize primeiro as funcionalidades obrigatórias.
* As funcionalidades opcionais somente deverão ser implementadas após a conclusão da versão básica.

---

# Resultado esperado

Ao final da atividade, o grupo deverá apresentar um aplicativo simples e funcional que permita cadastrar tarefas e armazená-las localmente no dispositivo.

O projeto deverá demonstrar, principalmente, a utilização prática dos blocos:

```text
StoreValue
GetValue
ClearTag
```

O aplicativo deverá continuar mostrando as tarefas cadastradas mesmo depois de ser fechado e aberto novamente.

A atividade mantém o foco técnico da pesquisa original, mas reduz o escopo para um projeto executável em poucas aulas.
