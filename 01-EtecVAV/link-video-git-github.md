# Link de Vídeos

## Git/Github

### O Git 

- é um sistema de controle de versão que permite acompanhar e gerenciar alterações em arquivos ao longo do tempo, sendo muito utilizado no desenvolvimento de software.

### Já o GitHub 

- é uma plataforma online que hospeda repositórios Git, facilitando o armazenamento, compartilhamento e colaboração entre desenvolvedores. Com essas ferramentas, é possível trabalhar em equipe de forma organizada, mantendo histórico de mudanças e evitando perda de dados. Além disso, o uso de versionamento permite testar melhorias sem comprometer o projeto principal. Por isso, Git e GitHub são essenciais para projetos modernos, tanto no ambiente acadêmico quanto profissional.
