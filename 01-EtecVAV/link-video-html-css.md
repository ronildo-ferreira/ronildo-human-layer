## HTML, CSS & JS

O HTML5 introduziu tags semânticas que descrevem claramente o seu significado tanto para o desenvolvedor quanto para o navegador. Em vez de utilizar apenas divisões genéricas, usamos elementos como ```<header>```, ```<main>``` e ```<footer>``` para estruturar o conteúdo. Essa prática melhora significativamente a acessibilidade para leitores de tela e otimiza o ranqueamento em motores de busca (SEO). Ao adotar a semântica, o código torna-se mais legível, organizado e profissional, facilitando a manutenção a longo prazo. É o alicerce para que a web entenda não apenas a aparência, mas o propósito de cada informação.

O CSS (Cascading Style Sheets) é o responsável por separar a estrutura do conteúdo da sua apresentação visual e design. Através de seletores e propriedades, ele define cores, fontes, espaçamentos e o posicionamento de cada elemento na tela.  Com a evolução para o CSS3, ganhamos ferramentas poderosas como Flexbox e Grid, que facilitam a criação de layouts complexos e responsivos. O uso correto de folhas de estilo garante que um site seja leve, elegante e consistente em diferentes dispositivos e navegadores. Dominar o CSS é transformar um esqueleto de código em uma interface funcional e atraente para o usuário final.


O JavaScript (JS) é a linguagem de programação que adiciona interatividade e comportamento dinâmico às páginas web estáticas. Enquanto o HTML estrutura e o CSS estiliza, o JS permite criar funções complexas, manipular dados e reagir a eventos do usuário em tempo real. Através da manipulação do DOM (Document Object Model), ele pode alterar elementos da página sem a necessidade de recarregá-la completamente. É uma linguagem versátil que evoluiu do navegador para o servidor, tornando-se essencial para o desenvolvimento de aplicações modernas e robustas. Dominar seus fundamentos é o passo definitivo para transformar um site simples em uma experiência digital completa e inteligente.

O Mobile-First é uma estratégia de design e desenvolvimento que prioriza a criação da experiência do usuário para telas pequenas antes de expandir para dispositivos maiores. Em vez de tentar "espremer" um site de desktop no celular, o desenvolvedor foca no conteúdo essencial e na performance desde o início. Tecnicamente, isso é feito utilizando *Media Queries* que aplicam estilos progressivos à medida que a largura da tela aumenta. Essa abordagem garante sites mais rápidos, leves e melhor ranqueados pelo Google, que prioriza a indexação móvel. É uma mudança de mentalidade que coloca a eficiência e a usabilidade acima de ornamentos visuais desnecessários.
