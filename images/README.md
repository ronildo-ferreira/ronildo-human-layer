
# Images

This directory stores images used across the repository documentation.

These assets are primarily used in README files, diagrams, conceptual explanations and visual elements that support the Human Layer project.

## Current Images

### ronildo-avatar.png

Author avatar used to represent the human identity behind this project.

This avatar symbolizes the **Human Layer** within the Zaion ecosystem — the perspective that connects technology, education and human reflection.

The avatar is intentionally stylized instead of using a real photograph in order to:

- maintain visual consistency across repositories
- avoid excessive personal exposure
- reinforce the symbolic nature of the Human Layer concept

## Usage

Images in this folder can be referenced in Markdown files like this:

<img src="images/ronildo-avatar.png" width="200">
