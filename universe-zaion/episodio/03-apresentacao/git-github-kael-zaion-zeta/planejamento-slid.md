## 🟦 Slide 2 — Problema

💡 No desenvolvimento de software:

- Como controlar mudanças no código?
- Como evitar perder versões anteriores?
- Como trabalhar em equipe sem conflitos?

👉 Surge a necessidade de **controle de versão**

---

## 🟦 Slide 3 — O que é Git?

📌 Git é um sistema de controle de versão

✔ Criado por Linus Torvalds (2005)  
✔ Permite salvar versões do projeto  
✔ Funciona de forma distribuída  

👉 Cada alteração vira um **registro (commit)**

---

## 🟦 Slide 4 — Como o Git funciona?

📌 Git funciona como uma linha do tempo:

- Versão 1 → Versão 2 → Versão 3  
- Histórico completo do projeto  
- Possibilidade de voltar no tempo  

💡 Analogia:  
👉 Como salvar várias versões de um trabalho  

---

## 🟦 Slide 5 — Por que usar Git?

✔ Organização  
✔ Segurança  
✔ Histórico de alterações  
✔ Trabalho em equipe  

👉 Muito usado no mercado de tecnologia  

---

## 🟦 Slide 6 — Instalação do Git

📥 Download:  
https://git-scm.com  

⚙ Após instalar:

```bash
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
````

---

## 🟦 Slide 7 — Comandos básicos

💻 Principais comandos:

```bash
git init
git add .
git commit -m "mensagem"
git status
git log
```

📌 Cada comando tem uma função no processo

---

## 🟦 Slide 8 — Exemplo prático

```bash
git init
git add index.html
git commit -m "primeira versão"
```

✏ Depois de modificar:

```bash
git add .
git commit -m "atualização"
```

👉 Criamos versões do projeto

---

## 🟦 Slide 9 — O que é GitHub?

🌐 GitHub é uma plataforma online

✔ Armazena projetos (repositórios)

✔ Permite colaboração 

✔ Baseado no Git 

👉 É como um “Google Drive de código”

## 🟦 Slide 12 — Integração Git + GitHub

🔗 Conectando local com remoto:

```bash
git clone URL
git push origin main
git pull origin main
```

📌 Clone → copiar projeto
📌 Push → enviar alterações
📌 Pull → atualizar projeto
