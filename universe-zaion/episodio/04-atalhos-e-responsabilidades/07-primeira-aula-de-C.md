## 🧠 Aula 1 — O que é um DADO


Zaion escreve:

— Dado é uma informação simples.

Exemplos:

- idade  
- nome  
- altura  
- velocidade  


— Um dado pode ser:

👉 Numérico  
- inteiro → 1, 2, 10  
- decimal → 3.5, 0.78  

👉 Alfabético  
- palavras → "Leo", "Zaion"  

👉 Alfanumérico  
- mistura → "Rua A, 123"


— Entendeu? — pergunta Zaion.

— Sim!

— Dado é informação.

— Pode ser número, texto ou mistura.

— Perfeito.

👉 Regra:

Dado sozinho = pouco útil  
Vários dados = informação completa

## 🧠 Aula 5 — Primeiro contato com C


— Agora sim…

— vamos ver C.

Zaion escreve:

```
#include <stdio.h>

int main() {
    printf("Olá, Leo!\n");
    return 0;
}
```

---


— Isso é um programa.

👉 main() → onde começa

👉 printf → mostra mensagem

👉 return 0 → terminou

---

— Não precisa entender tudo agora.

— Só reconhecer.

Leo olha para o código.

Dessa vez…

sem medo.

— Acho que agora faz sentido.

Zaion sorri.


Leo olha para o código com atenção.

— Mano… o que é isso aqui?

— Esse `\n` no final?


— Boa pergunta.

— Isso se chama **quebra de linha**.

— O `\n` significa:
>
>👉 "vá para a próxima linha"
>


Zaion escreve:

```
printf("Linha 1");
printf("Linha 2");
```

— Isso vai sair assim:

```
Linha 1Linha 2
```

---

## Agora com \n

```
printf("Linha 1\n");
printf("Linha 2");
```

— Agora fica:

```
Linha 1
Linha 2
```

---

— É como apertar **Enter** no teclado.

---

— O `\n` é um **caractere especial**.

— Ele não aparece…

— mas controla o formato do texto.

— Então…

— ele não imprime nada…

— mas muda a linha?

— Exatamente!

Leo sorri.

— Pequeno… mas importante.

Zaion confirma.

— Em programação…

— os detalhes fazem toda a diferença.

— Amanhã…

— a gente começa de verdade.
