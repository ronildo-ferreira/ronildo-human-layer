### 📌 Comandos básicos do Git

#### git add teste.c

👉 Adiciona o arquivo para o próximo salvamento\
👉 É como “selecionar” o que você quer guardar

---

#### git commit -m "Primeiro programa em C"

👉 Salva uma versão do projeto\
👉 É como tirar uma “foto” do código

---

#### git push origin main

👉 Envia o código para o GitHub\
👉 Atualiza o repositório online

---

— Agora digita isso:

```
git add teste.c
git commit -m "Primeiro programa em C"
git push origin main
```
