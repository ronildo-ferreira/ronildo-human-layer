# Episódio 01 — De Volta às Aulas

## 📌 Sinopse

Após um acidente que não consegue explicar, Zaion percebe que algo mudou.

Uma voz.

Um eco.

Uma presença que não deveria existir.

Enquanto tenta retomar sua rotina escolar — entre amigos, novas responsabilidades e um projeto envolvendo Git e GitHub — ele começa a perceber que nem tudo ao seu redor segue as mesmas regras de antes.

Memórias inconsistentes.

Dados que não deveriam existir.

E um androide que sabe mais do que deveria.

No meio disso tudo, surge Kael — e, com ela, a sensação de que algo maior está começando.

Mas uma pergunta permanece:

👉 O que realmente aconteceu naquele dia?

## 🎯 Sobre

Este episódio marca o início de uma transformação.

Após um evento que não consegue explicar, Zaion passa a perceber falhas naquilo que sempre chamou de realidade — memórias que não se encaixam, sinais que não deveriam existir e uma presença que ultrapassa os limites da própria mente.

Entre a rotina escolar e novas responsabilidades, ele começa a compreender que algo maior foi iniciado… mesmo sem saber ainda o quê.

---

## 🎓 Objetivo pedagógico

Este episódio integra narrativa e aprendizagem para introduzir conceitos de:

- Git (controle de versões)  
- GitHub (colaboração em projetos)  
- Trabalho em equipe e organização de ideias  

A proposta é aprender por meio da experiência dos personagens, conectando tecnologia a situações reais e emocionais.
